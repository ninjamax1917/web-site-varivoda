# Мой проект - это современный веб сайт, построенный с помощью HTML5, TailwindCSS, DaisyUI, PHP, Laravel.

**Видеотрансляция**
На веб сайте есть возможность просмотреть прямую трансляцию с городских камер видеонаблюдения.
Трансляция реализуется с помощью медиасервера "MEDIAMTX" (https://github.com/bluenviron/mediamtx) и встроенного в сервер - WebRTC. 
Потоки отбираются с камер видеонаблюдения по протоколу - RTSP.
